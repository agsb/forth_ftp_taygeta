\ There used to be a voice sythesizer board sold for the Apple or
\ computers with a parallel port called Digitalker.  
\ This may still be available for all I know. 
\ I used it on a Z-80 S100 Forth-79 system. 
\ The board had a ROM of a fixed set of available words.

\ Below are the definitions for words available as well as a way to deal
\ with numbers.  A separate vocabulary was used since some of the words
\ conflicted with normal Forth words.

\ SPEAK outputs the number on the stack to the digitalker parallel port
\ SPEAK# speaks the number on the stack, ie. 'one hundred twenty three' 

\ The names are defined as specific code# outputs.
\ If I were writing this today I'd probably define-
\  : SAY   ( n SAY <name>  )     \ compile time, like a constant
\          ( <name>    | speaks name )   \ run time
\   create ,  does>  @ speak ;

\ Example-   88 SAY GREAT  would create GREAT which would say 'GREAT'
\ when executed.

\ This is another example of something much more useful in Forth than
\ other languages.  The words can be typed as a sentence or used in
\ a defined sentence just like English making the definitions easy to read.
\ No more thinking about the actual code#s.  
\ The interaction allowed experimentation for the best phrasing.

 ( digitalker  numbers )   

\ numbers for digitalker use the lower code#s for 1 to 19
\ zero, tens, hundreds, and thousands are special cases    
                             
: BELOW.TWENTY  ( n -- | speaks the positive number below 20 )
                (        handles teens and zero )
    ?dup  if  speak  else  zero then ; 
               
: TENS  ( n -- n1  | speaks the positive number in increments of 10 )
        (       'twenty', 'thirty', etc. and leaves the remainder n1 )
    10 /mod  2 -  20 +  speak ; 
                                
: TENS.RANGE  (  n   -- | speaks the positive number between 99 and 0)
    dup 19 > 
        if tens dup 0=  
            if drop exit then      \ exit if exactly a tens increment    
        then   
      below.twenty ; 
                                        
: HUNDREDS.RANGE  ( n -- | speaks the positive number between 999 and 0)
    dup 99 > 
        if 100 /mod tens.range hundred   dup 0= 
            if drop exit then    \ exit if exactly a hundreds increment  
        then     tens.range ;  
               
: THOUSANDS.RANGE   ( n --  | speaks the positive number )
                    (        between 999999 and 0)
        dup 999 > 
            if 1000 /mod  hundreds.range         
              thousand dup 0= 
                if drop exit then    \ exit if exactly a thousands increment  
            then     hundreds.range ;  
  
: SPEAK#   ( n -- | speaks the number )
        dup 0<    
             if  minus abs then   \ say 'minus' then covert to absolute
                thousands.range ;

               ( 'stop at' n 'point' n1 'inches please')
     swap    stop at   speak#  point   speak# inches please ;
