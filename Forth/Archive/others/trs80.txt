*** MODEL-I/III/IV-FORTH 21-MAR-84
  PARENT=TRS-80               USAGE=623
The Alternate Source (704 N. Pennsylvania Ave. Lansing, Mi. 48906
is distributing The Alternate Forth for Models I, III and IV TRS-80s.
It is a very nice implementation of Z-80 FIG-Forth 1.1 with many
extensions.  The Model I version supports lowercase mods, double
density mods, and high-speed clock mods.  Utilities include:
Full-screen editor
Assembler
Decompiler
Cross-reference
Word search
Forthdos (file manipulation, etc.  Written in high-level Forth!)
PDRIVE (set up special disk parameters - double sided, etc.)
Real-time clock support
Oodles of other words, too!
The Alternate Forth is $79.95 from The Alternate Source.
This price includes Z-80 source code on disk!  A hacker's delight!

to tht Model I version!)
