                        I n t r o d u c t i o n

WPFORTH Version 1.0 is a prototype of Typographical Programming System
built around WordPerfect Version 5.x and Mr. Frank C. Sergeant's Pygmy
Forth Version 1.4.  WPFORTH is a public domain product, but it is
copyrighted.  That means you can freely distribute WPFORTH to others
provided that NO modification to WPFORTH is made, NO file is missing,
and NO charge is involved.

However, Pygmy Forth is not in public domain, it is a shareware.  If you
want to build WPFORTH yourself from the included source code, you'll
need a copy of Pygmy FORTH Version 1.4.  You are required to register
your Pygmy FORTH copy with Mr. Sergeant if you want to use it on a
regular basis.  For more details about Pygmy Forth, contact Mr. Sergeant
at the following address:

                  Frank C. Sergeant 
                  809 W. San Antonio St. 
                  San Marcos, Texas 78666

He can also be reached via bitnet as fs07675@swtexas.

                   F i l e s   D e s c r i p t i o n

The archive contains several files, they are:

        WPFORTH.DBL - Definitions of double number operations
        WPFORTH.DEF - Definitions of defining words
        WPFORTH.EXE - Executable file
        WPFORTH.F   - Main WPFORTH routine
        WPFORTH.FIL - Definitions of file operations
        WPFORTH.FON - Definitions to handle fonts
        WPFORTH.LOD - Definitions to load files
        WPFORTH.PFX - Definitions to handle WordPerfect prefix
        WPFORTH.SAV - Definitions of save operations
        WPFORTH.UTL - Definitions of some utility words
        WPFORTH.VAR - Definitions of all variables and constants used
        WPFORTH.WPF - Definitions to handle WordPerfect functions

========================================================================

Notes : in this section, <ENTER> means to press the <ENTER> or <RETURN>
        Key, not to type the word "<ENTER>"

To use WPFORTH, you need an IBM PC or compatible with at least 256K
bytes of memory after DOS and all TSR's are loaded.  The operating
system must be MSDOS/PCDOS Version 2.0 or above.

To install WPFORTH, you just have to create a directory and copy all the
files into that directory.

To run WPFORTH, change to the WPFORTH directory and at the DOS prompt,
enter the following command:

        C:\WPFORTH>WPFORTH <ENTER>

To create WPFORTH from the source, you need a copy of Pygmy Forth
installed in the same directory, at Pygmy's ok prompt, enter the
following commands:

        ok INCLUDE WPFORTH.F <ENTER>
        ok SAVE WPFORTH.EXE <ENTER>
        ok BYE <ENTER>

Note that Pygmy FORTH is case sensitive, so you must enter the above
commands as shown.

For information on how to install Pygmy Forth, refer to the
documentation that comes with Pygmy.
